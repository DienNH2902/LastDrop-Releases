# Last Drop Arena — tải game

Battle royale FPS góc nhìn thứ nhất của **D.I.E.N Studio**: nhảy dù, lục soát, đấu súng, lái xe và sống sót đến người cuối cùng.

## Tải về

| Hệ điều hành | Tệp |
| --- | --- |
| **Windows 10 / 11** (khuyên dùng) | [LastDrop.exe](../../releases/latest/download/LastDrop.exe) |
| macOS Apple Silicon (M1 trở lên) | [LastDrop-mac-arm64.dmg](../../releases/latest/download/LastDrop-mac-arm64.dmg) |
| macOS Intel | [LastDrop-mac-x64.dmg](../../releases/latest/download/LastDrop-mac-x64.dmg) |

Hoặc vào mục [Releases](../../releases/latest) để chọn tệp.

- Bản Windows là tệp chạy thẳng (portable), không cần cài đặt, tự báo khi có bản mới.
- Windows có thể hiện cảnh báo SmartScreen vì tệp chưa ký số: chọn **More info** rồi **Run anyway**.
- Chơi trên trình duyệt (khuyên dùng Google Chrome) thì không cần tải gì.

Kho này chỉ chứa bản cài, được cập nhật tự động mỗi khi có phiên bản mới.
